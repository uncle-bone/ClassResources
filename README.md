# ClassResources

ClassResources is a class-aware resource tracker for World of Warcraft: Forever.

## Current stable release

**Version:** 0.3.9  
**Client interface:** 16001

- [Download ClassResourcesForever v0.3.9](https://github.com/uncle-bone/ClassResources/releases/download/v0.3.9/ClassResourcesForever.zip)
- [Release notes](https://github.com/uncle-bone/ClassResources/releases/tag/v0.3.9)

The release ZIP contains the complete installable addon folder, source, documentation, and attribution records.

## Install

1. Download and extract `ClassResourcesForever.zip`.
2. Copy the `ClassResourcesForever` folder into `_forever_/Interface/AddOns/`.
3. Enable it in the AddOns list at character select.

The package includes Druid and Rogue trackers, shared resource and cooldown trackers for the other classes, and proc alerts. See the in-package README and ProcCatalog for details and known verification limits.
